RGB Coding 문제 풀이

문제 2번, 5번 상세 풀이

문제 2번

문제: If you drop the blue component of the color #FF1468 by 80%, what is the new hexadecimal color code?

번역: 색상 #FF1468의 파란색(blue) 구성 요소를 80% 감소시키면 새로운 16진수 색상 코드는 무엇입니까?
1단계: 16진수 색상 코드 분해하기
색상 코드 #FF1468을 RGB 구성 요소로 분해합니다:
#FF1468 = RGB(FF16, 1416, 6816)
  • Red (빨간색): FF16
  • Green (녹색): 1416
  • Blue (파란색): 6816 ← 이것을 80% 감소시켜야 함
2단계: 파란색(Blue) 값을 10진수로 변환하기
파란색 구성 요소만 10진수로 변환합니다:
6816 = 6 × 16 + 8 = 96 + 8 = 10410
따라서 현재 파란색 값은 104입니다.
3단계: 파란색 값을 80% 감소시키기
현재 파란색 값: 104
80% 감소한다는 것은 원래 값의 20%만 남는다는 의미입니다:
새로운 Blue 값 = 104 × (100% - 80%) = 104 × 20% = 104 × 0.20 = 20.8
RGB 값은 정수여야 하므로 버림(내림)하면:
새로운 Blue 값 = 20
4단계: 새로운 10진수 값을 16진수로 변환하기
Red와 Green은 변경되지 않았으므로 그대로 유지:
  • Red: 25510 = FF16
  • Green: 2010 = 1416
새로운 Blue 값을 16진수로 변환:
2010 = 1 × 16 + 4 = 1416
5단계: 최종 16진수 색상 코드 조합하기
새로운 RGB 값을 16진수로 조합:
새로운 색상 코드 = #FF1414
→
원래 색상                      새로운 색상
정답: #FF1414

문제 5번

문제: A color has a red value of 79, a green value of 118, and a blue value of 54. What is its hexadecimal color code?

번역: 색상의 빨간색 값이 79, 녹색 값이 118, 파란색 값이 54일 때, 16진수 색상 코드는 무엇입니까?
1단계: 주어진 RGB 값 확인하기
Red (R) = 7910
Green (G) = 11810
Blue (B) = 5410
각 값을 16진수로 변환해야 합니다.
2단계: Red 값(79)을 16진수로 변환하기
10진수 79를 16진수로 변환 (나눗셈 방법):
나누는 수 몫 나머지
16 79 -
16 4 15 (F)
16 0 4
7910 = 4 × 16 + 15 = 4F16
나머지를 아래에서 위로 읽으면: 4F16 (15는 16진수에서 F로 표현)
3단계: Green 값(118)을 16진수로 변환하기
10진수 118을 16진수로 변환:
나누는 수 몫 나머지
16 118 -
16 7 6
16 0 7
11810 = 7 × 16 + 6 = 7616
나머지를 아래에서 위로 읽으면: 7616
4단계: Blue 값(54)을 16진수로 변환하기
10진수 54를 16진수로 변환:
나누는 수 몫 나머지
16 54 -
16 3 6
16 0 3
5410 = 3 × 16 + 6 = 3616
나머지를 아래에서 위로 읽으면: 3616
5단계: 16진수 색상 코드 조합하기
각 구성 요소의 16진수 값을 순서대로 조합:
RGB(79, 118, 54) = RGB(4F16, 7616, 3616)
색상 코드 = #4F7636
이 색상입니다
검증: 16진수를 다시 10진수로 변환하여 확인
#4F7636 = RGB(4F16, 7616, 3616)
= RGB(4×16+15, 7×16+6, 3×16+6)
= RGB(64+15, 112+6, 48+6)
= RGB(79, 118, 54) ✓
원래 값과 일치하므로 정답이 맞습니다!
정답: #4F7636

핵심 개념 정리

1. 10진수 → 16진수 변환

  • 수를 16으로 나누고, 나머지를 오른쪽에서 왼쪽으로 읽습니다.
  • 10~15는 A~F로 표현합니다 (A=10, B=11, C=12, D=13, E=14, F=15).

2. 16진수 → 10진수 변환

  • 각 자릿수에 16의 거듭제곱을 곱하여 더합니다.
  • 예: 4F16 = 4×16¹ + 15×16⁰ = 64 + 15 = 7910

3. RGB 색상 코드 형식

  • 형식: #RRGGBB (각각 2자리 16진수)
  • 각 값의 범위: 0~255 (0016~FF16)
  • 퍼센트 계산 시 결과는 0~255 범위 내로 제한됩니다.
